# STEM-проєкт: Аналіз та обробка біометричних зображень

Цей проєкт реалізує конвеєр обробки біометричних зображень (відбитків пальців датасету FVC) за допомогою класичних методів комп'ютерної графіки. 

Особливістю проєкту є те, що всі алгоритми та математичні метрики реалізовані **вручну** за допомогою матричних обчислень (`NumPy`) без використання оптимізованих функцій сторонніх бібліотек комп'ютерного зору (таких як OpenCV). Проєкт відповідає експертному рівню складності, містить обробку крайніх випадків, 100% покриття статичним аналізатором коду та модульні автотести.

## Реалізовані алгоритми (6 методів)
Проєкт охоплює алгоритми з 6 різних категорій обробки зображень:
1. **Просторова фільтрація:** Медіанний фільтр (ізоляція імпульсного шуму).
2. **Контурний аналіз:** Фільтр Собеля (виділення градієнтів та меж).
3. **Гістограмна корекція:** Гістограмне вирівнювання (розширення динамічного діапазону).
4. **Сегментація зображень:** Метод Оцу (автоматичний підбір порогу бінаризації).
5. **Морфологічна обробка:** Морфологічна ерозія (звуження об'єктів).
6. **Аналіз текстур:** Локальні бінарні шаблони / LBP (векторизоване виділення текстурних ознак).

## Структура проєкту
* `main.py` — головний скрипт, що виконує конвеєр обробки зображень, обробляє винятки (пошкоджені файли) та зберігає результати.
* `processors.py` — ООП-реалізація всіх математичних алгоритмів обробки (класи фільтрів).
* `metrics.py` — формули для обчислення метрик якості (MSE, PSNR, SSIM).
* `test_processors.py` — набір модульних автотестів для перевірки коректності логіки алгоритмів на базових матрицях 3x3.
* `config.json` — конфігураційний файл для налаштування параметрів методів (розміри ядер, кількість ітерацій) без втручання в код.
* `images/input/` — директорія для вхідних зображень (рекомендується $\ge100$ зображень формату .tif, .bmp, .png).
* `images/output/` — директорія, куди зберігаються оброблені зображення та файл `metrics.csv`.

## Інструкція із запуску

1. Переконайтеся, що ви знаходитесь у кореневій папці проєкту. Створіть та активуйте віртуальне середовище Python:
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # Для macOS/Linux

2. Проєкт використовує лише базові бібліотеки для роботи з матрицями та читання файлів:
pip install numpy Pillow

3. Для перевірки математичної коректності алгоритмів на еталонних матрицях виконайте:
python3 -m unittest test_processors.py

4. Код проєкту написаний згідно зі стандартом PEP-8 та має оцінку 9.59/10. Для перевірки встановіть лінтер (pip install pylint) та виконайте:
pylint main.py processors.py metrics.py test_processors.py
