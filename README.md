# Аналіз та обробка біометричних зображень

Проєкт ініціалізує 5 методів зображенб ( медаінний фільтр, фільтр Собеля гістограмне вирівнювання, метод Оцу, ерозія).

## Інструкція запуску
1. Створіть віртуальне середовище: `python -m venv venv`
2. Активуйте його: `source venve/bin/activate`
3. Встановіть залежності: `pip install -r requirements.txt`
4. Розмістіть вхідні зображення у папці `images/input`
5. Запустіть програму: `python3 main.py`
